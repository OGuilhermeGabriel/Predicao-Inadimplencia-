# Case Técnico Cientista de Dados Júnior - DataRisk

Este README irá conter apenas a visão geral da solução feita para um case técnico de Cientista de Dados realizado. Nesse problema, minha tarefa foi criar um modelo para realizar a predição da taxa de inadimplência dos clientes que estão `base_pagamentos_teste`. Para informações da problemática, recomendo conferir `Case DS Júnior 2025.pdf`.

**A solução aprofundada e detalhada está no notebook `Data Analysis.ipynb`.**

---

## Bibliotecas Utilizadas

Logo abaixo estão as bibliotecas que foram utilizadas de forma direta no notebook `Data Analysis.ipynb`:

- Pandas
- Numpy
- Matpotlib
- Scikit learn

Caso deseje saber mais sobre as bibliotecas secundárias utilizadas de forma indireta (construção do ambiente virtual, do jupyter notebook), confira o arquivo `requirements.txt`.
